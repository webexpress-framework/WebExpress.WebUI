# Structured content and context extensions

The editor format is recognized by its supported version, document root and valid node shapes. `EditorState.IsState` rejects malformed JSON, unrelated objects, workbooks and ambiguous documents containing both formats. `EditorState.ToPlainText` extracts words directly from the validated model, preserves inline word boundaries and separates blocks with spaces. It returns an empty string for an empty document and throws `JsonException` for invalid input. `EditorState.IsEmpty` uses content positions so images and other atomic content remain nonempty.

The spreadsheet format is recognized by its sheets array and supported version when present. `SpreadsheetWorkbook.IsWorkbook` rejects unrelated JSON, editor documents and invalid workbooks. `Parse` continues to accept blank input as a new empty workbook and supports existing unversioned workbook input. `ToPlainText()` and `ToPlainText(json)` expose effective cell values and structured captions in sheet and row order. Empty workbooks produce empty text. Malformed nonempty input throws `JsonException`. Renderer-specific conversions between prose and spreadsheets remain application responsibilities.

The menu visibility extension evaluates `ControlDropdownItemLink.Visible` with the current render context on every render. It does not modify shared menu state. The dropdown overload accepting an item collection renders that collection. Applications must independently authorize every server operation regardless of whether its menu entry is visible.

The form title extension uses `ControlForm.TitleInputFactory` to construct a fresh title input for each request. The item participates in initialization, validation and form submission and appears once in the header. It carries the existing modal title styling marker. The factory must return a new control and avoid capturing mutable user state in a cached fragment. Its inputs are not retained in the form's shared item collection.

The document add-ons use the existing editor registry. `toc` lists document headings, `callout` provides editable notice content with a title and tone, and `status` provides freely editable label text and a tone. Labels and options are localized in German and English. Configuration and child content persist in the editor JSON model. The editor and reading view share their presentation, while the table of contents uses text entries during editing and heading links while reading. Server HTML export supports the same general add-ons. It collects heading captions once and rejects contents expansion above 50,000 generated nodes or 8,000,000 encoded caption and list item characters with `JsonException` before building the repeated output. Object references, object queries and workspace content remain application extensions.
